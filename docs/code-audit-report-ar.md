# تقرير التدقيق والتنفيذ — Hola

**الفرع:** `arena/54cb6f64-demo`
**تاريخ التقرير:** 16 نوفمبر 2026
**النطاق:** تطبيق تعليم الإسبانية، تجربة الأجهزة المختلفة، المحاضرات، الجرامر، الاستماع، التحدث، الألعاب، الاختبارات، وحالة مواد Drive.

## الملخص التنفيذي

أُعيد تنظيم التطبيق إلى أقسام مستقلة داخل صفحة React واحدة، وأضيف اختيار مستوى من الملف الشخصي يحفظ على الجهاز ويصفّي محتوى المحاضرات والتمارين. أضيفت صفحات مستقلة للاستماع والتحدث والجرامر وQuiz وFlashcards والامتحانات وصالة الألعاب. الواجهات لا تعرض للطالب روابط Drive أو ملاحظات تقنية عن تخزين الملفات.

هذه **خطوة تنفيذ كبيرة، وليست إتمامًا لكل طلبات السجل**. بعد فحص إضافي لحزم Drive الأصلية، أُضيفت قارئات A2.2/A2.3 وصفحاتها وصوتياتها إلى جانب A1.1–A1.3 وA2.1. ما زال التطبيق يحتوي 20 درسًا نموذجيًا؛ استيراد المواد المحددة لا يعني أن كل صفحات/أنشطة الكتب أصبحت درسًا تفاعليًا كاملًا، ولا يثبت استعادة أرشيف التسجيلات والترجمات التاريخي 56/861.

## بيانات فعلية وحدود التغطية

- `src/data/lessons.js`: 10 نماذج A1 و10 نماذج A2، في كل درس مفردات ومثال وسؤال قصير. هذا ليس كامل الكتاب ولا تفريغًا كاملًا للمواد الأصلية.
- `src/data/grammar.js`: شروح أصلية بالمصري لكل الدروس العشرين.
- `src/data/sentences.js`: 3 جمل إضافية لكل درس لآلية ترتيب الجمل.
- `src/data/stories.js`: قصة قصيرة بالإسبانية وترجمتها العربية لكل درس.
- `src/data/listening.js` و`public/materials/*/activity-data.json` و`listening-translations.json`: 20 مثالًا محليًا مترجمًا. لا تمثل أرشيف 56 تسجيلًا و861 صفًا، ولم تُنشأ ترجمات مزعومة للبيانات المفقودة.
- `src/data/courseMaterials.js` و`public/materials/books/`: 362 صورة صفحات WebP فريدة و120 ملف MP3؛ للوحدات A1 0–9 وA2 1–10، عبر المراحل الست A1.1–A1.3 وA2.1–A2.3. تربط الخريطة كل صفحة ومسار صوت بالدرس والصفحة المصدرية. تفصيل المصادر في `docs/course-materials-import-manifest.json` و`docs/course-materials-recovery-ar.md`.

## بنود لم تكتمل — لا تعتبرها منفذة

1. **اكتمال استيراد المنهج الأصلي:** تُفتح قارئات HTML الأصلية للمراحل الست داخل نافذة الدرس؛ كما تُعرض صفحات وصوتيات محددة ببطاقات React. حُفظ فهرس الإجابات والطبقات الموجود داخل القارئ، لكن لم تُنقل كل صفحات/أنشطة كل ZIP إلى بطاقات منفصلة، ولا تُعد الدروس النموذجية شرحًا كاملًا لكل صفحة.
2. **اكتمال المنهج A1/A2:** توجد الوحدات النموذجية العشر لكل مستوى، لكن لا يوجد بعد المحتوى الكامل لكل صفحة/نشاط في الكتاب، ولا مطابقة تحريرية لكل سؤال مع المدرس والكتاب.
3. **الصور التعليمية لكل درس:** توجد رسمة SVG أصلية عامة وبعض الرموز؛ لم تُنشأ مكتبة صور مستقلة مرتبطة بكل درس.
4. **اكتمال التسجيلات والترجمات:** في التطبيق 120 ملف MP3 أصليًا/بديلًا من الحزم المفحوصة؛ حزم A2.2/A2.3 تضيف 58 ملفًا (46+12). لم يُعثر بعد على مصدر يطابق الأرشيف التاريخي 56 تسجيلًا و861 صف ترجمة: الملف المستعاد `transcripts_v17.json` يضم 24 مسارًا و401 سطر تقريبًا، و`transcripts_raw.txt` تفريغ إسباني مطبوع من A1. لا توجد ترجمة عربية سطرية موثقة لكل التسجيلات، ولا يجوز اعتبار الجمل النموذجية ترجمة لها.
5. **تصحيح التحدث:** التصحيح يقارن النص الذي تعرّف عليه المتصفح بالنموذج؛ ليس تقييمًا صوتيًا متخصصًا للمخارج أو اللكنة. دعم المايك يعتمد على متصفح يدعم SpeechRecognition وإذن المستخدم.
6. **حساب ومزامنة سحابية:** الملف والتقدم محفوظان في الجهاز الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة عبر الأجهزة.
7. **المستويات B1 إلى C1:** تظهر كخريطة طموح في بعض أجزاء الخطة، لكن الوحدات والأنشطة الفعلية غير موجودة.
8. **الاختبار البصري الآلي:** لم تُستخدم أداة متصفح آلي في هذا التحقق؛ يجب تجربة العرض على هاتف/لابتوب فعليين، خصوصًا أذونات الميكروفون والتنسيق.
9. **مستند الرسائل الحرفي:** ملف `docs/user-requests-verbatim.md` أُنشئ سابقًا لكنه لا يثبت اكتمال أو حرفية جميع رسائل السجل، ولا ينبغي اعتباره مصدرًا مرجعيًا لتوسيع المتطلبات.

## نتائج التحقق البرمجي

- `npm run quality:check`: **نجح — 562 assertion** على بيانات الدروس العشرين وسلوكها. ويتضمن فحص مواد الكتب: **1,987 تحققًا** على 362 صورة WebP فريدة و120 ملف MP3، مع المسارات والتغطية والصيغ.
- `npm run build`: **نجح** باستخدام Vite.
- `git diff --check`: **نجح**.

هذه النتائج تثبت بناء التطبيق وفحوص الاتساق المحددة فقط؛ لا تثبت اختبار واجهة بمتصفح حقيقي ولا استيراد ملفات Drive ولا اكتمال المنهج.

## توصيات المرحلة التالية

1. استكمال البحث عن المصدر الموثوق لأرشيف 56 تسجيلًا و861 صف ترجمة، ومطابقة أي نسخة جديدة مع الملفات الحالية قبل دمجها. قُرئت حزم A2.2/A2.3 الحالية وفُحصت بالفعل؛ لا تُعدّ استعادتها إثباتًا لاكتمال الأرشيف التاريخي.
2. تشغيل تجربة متصفح بصرية/صوتية فعلية على الهاتف واللابتوب، خصوصًا تشغيل الصوت، سرعته، وتحميل الصور داخل المحاضرة.
3. مطابقة كل درس ونشاط وقاعدة مع ملفات الكتاب/المدرس، وتوسيع بنوك الأسئلة والقصص بعد التحقق من المصدر.
4. اختبار فعلي للهاتف واللابتوب والميكروفون، ومعالجة نتائج المتصفحات غير الداعمة برسالة واضحة.
5. إنشاء تقرير تحقق منفصل لكل حزمة أصلية بعد اكتمال استيرادها؛ لا تخلط بيانات الأمثلة الحالية بأرشيف التسجيلات التاريخي.
