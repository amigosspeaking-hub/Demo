# تقرير التدقيق والتنفيذ — Hola

**الفرع:** `arena/54cb6f64-demo`
**تاريخ التقرير:** 16 نوفمبر 2026
**النطاق:** تطبيق تعليم الإسبانية، تجربة الأجهزة المختلفة، المحاضرات، الجرامر، الاستماع، التحدث، الألعاب، الاختبارات، وحالة مواد Drive.

## الملخص التنفيذي

أُعيد تنظيم التطبيق إلى أقسام مستقلة داخل صفحة React واحدة، وأضيف اختيار مستوى من الملف الشخصي يحفظ على الجهاز ويصفّي محتوى المحاضرات والتمارين. أضيفت صفحات مستقلة للاستماع والتحدث والجرامر وQuiz وFlashcards والامتحانات وصالة الألعاب. الواجهات لا تعرض للطالب روابط Drive أو ملاحظات تقنية عن تخزين الملفات.

هذه **خطوة تنفيذ كبيرة، وليست إتمامًا لكل طلبات السجل**. ما زالت حزم HTML/ZIP الأصلية، صور الكتاب، وصوتياته غير مستوردة محليًا. الموجود حاليًا 20 درسًا نموذجيًا ببيانات محلية، ولا يصح وصفه بأنه المنهج الكامل أو أرشيف التسجيلات القديم.

## ما تم تنفيذه

| الطلب | الحالة الحالية |
|---|---|
| تصفية الواجهة حسب مستوى المتعلم وإعداد المستوى من الملف الشخصي | منفّذ للمراحل A1.1–A1.3 وA2.1–A2.3؛ يحفظ الاختيار في `localStorage` |
| إبقاء التنقل والمواد في نفس الموقع | منفّذ: صفحات مستقلة داخل تطبيق React؛ لا روابط Drive في واجهة الطالب |
| فصل المحاضرات عن أدوات الاستماع والامتحان والتدريب | منفّذ: المحاضرات والجرامر والاستماع والتحدث والألعاب وQuiz وFlashcards والامتحانات لكل منها شاشة مستقلة |
| لعبة مستقلة لكل نشاط مع بنك خاص بالدرس | منفّذ كنماذج أولية لأربع آليات: المطابقة، أسئلة اختيار، استماع واختيار، وترتيب الجمل؛ تتغير الأسئلة/الجمل حسب الدرس |
| الوقت والقلوب والنقاط والتغذية الراجعة | منفّذ في شاشة اللعب؛ الاختيار الصحيح أخضر والخاطئ أحمر، ولا تظهر نافذة منبثقة عند كل خطأ |
| فصل Quiz والامتحان عن شاشة المحاضرة | منفّذ بصفحتين مستقلتين؛ الامتحان موقّت وبنك الأسئلة يتحدد بالمستوى/المحاضرة |
| Flashcards وبنك الكلمات | منفّذ؛ قلب البطاقة بلون وخط متباينين، وحفظ الكلمات يظهر في القاموس والبطاقات |

| الاستماع والترجمة وإخفاء العربية | منفّذ في `ListeningPage`: الجملة الإسبانية LTR على اليسار والترجمة العربية على اليمين، بزر إظهار/إخفاء، وسرعات 0.5 و0.75 و1 و1.25 |
| التحدث من المايك فقط | منفّذ باستخدام SpeechRecognition/WebKit SpeechRecognition إن دعمه المتصفح؛ مقارنة كلمة بكلمة؛ لا يوجد حقل كتابة |
| قصص تدريب ثنائية اللغة مرتبطة بالدرس | أضيفت 20 قصة قصيرة في `src/data/stories.js` |
| RTL للعربية وLTR للإسبانية وتصميم متجاوب | منفّذ في الصفحات الجديدة والتنقل السفلي القابل للتمرير على الهاتف؛ أضيفت ألوان إسبانية حمراء/ذهبية إلى الواجهة |
| إزالة الإحصاءات الافتراضية غير الحقيقية | أزيل الاسم الافتراضي الأنثوي والستريك/الدقائق المصطنعة؛ الإنجاز يعكس الأنشطة المسجلة محليًا |
| عدم مخاطبة المستخدم بصيغة مؤنثة | عُدّلت عبارات الواجهة الرئيسية إلى صيغة المذكر/المحايد، وأمثلة التعريف صارت باسم عمر |

## بيانات فعلية وحدود التغطية

- `src/data/lessons.js`: 10 نماذج A1 و10 نماذج A2، في كل درس مفردات ومثال وسؤال قصير. هذا ليس كامل الكتاب ولا تفريغًا كاملًا للمواد الأصلية.
- `src/data/grammar.js`: شروح أصلية بالمصري لكل الدروس العشرين.
- `src/data/sentences.js`: 3 جمل إضافية لكل درس لآلية ترتيب الجمل.
- `src/data/stories.js`: قصة قصيرة بالإسبانية وترجمتها العربية لكل درس.
- `src/data/listening.js` و`public/materials/*/activity-data.json` و`listening-translations.json`: 20 مثالًا محليًا. لا تمثل أرشيف 56 تسجيلًا و861 صفًا، ولم تُنشأ ترجمات مزعومة للبيانات المفقودة.

## بنود لم تكتمل — لا تعتبرها منفذة

1. **استيراد ملفات المحاضرات الأصلية وصورها وصوتياتها محليًا:** واجهة الدروس الحالية React ومحتوى نموذجي. ملفات HTML والحزم المضغوطة ذات المجلدات النسبية لا تزال غير منسوخة إلى التطبيق. لذلك لم يُنفّذ قارئ الكتاب الأصلي ولا تشغيل تسجيلاته.
2. **اكتمال المنهج A1/A2:** توجد الوحدات النموذجية العشر لكل مستوى، لكن لا يوجد بعد المحتوى الكامل لكل صفحة/نشاط في الكتاب، ولا مطابقة تحريرية لكل سؤال مع المدرس والكتاب.
3. **الصور التعليمية لكل درس:** توجد رسمة SVG أصلية عامة وبعض الرموز؛ لم تُنشأ مكتبة صور مستقلة مرتبطة بكل درس.
4. **تسجيلات الكتاب:** الموجود في المشغل الحالي نطق Speech Synthesis من الجهاز، لا مشغل التسجيلات الأصلية. دعم الصوت وجودة الصوت الإسباني يعتمدان على المتصفح والجهاز.
5. **تصحيح التحدث:** التصحيح يقارن النص الذي تعرّف عليه المتصفح بالنموذج؛ ليس تقييمًا صوتيًا متخصصًا للمخارج أو اللكنة. دعم المايك يعتمد على متصفح يدعم SpeechRecognition وإذن المستخدم.
6. **حساب ومزامنة سحابية:** الملف والتقدم محفوظان في الجهاز الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة عبر الأجهزة.
7. **المستويات B1 إلى C1:** تظهر كخريطة طموح في بعض أجزاء الخطة، لكن الوحدات والأنشطة الفعلية غير موجودة.
8. **الاختبار البصري الآلي:** لم تُستخدم أداة متصفح آلي في هذا التحقق؛ يجب تجربة العرض على هاتف/لابتوب فعليين، خصوصًا أذونات الميكروفون والتنسيق.
9. **مستند الرسائل الحرفي:** ملف `docs/user-requests-verbatim.md` أُنشئ سابقًا لكنه لا يثبت اكتمال أو حرفية جميع رسائل السجل، ولا ينبغي اعتباره مصدرًا مرجعيًا لتوسيع المتطلبات.

## توصيات المرحلة التالية

1. استيراد ملفات المستوى من الحزم الأصلية على دفعات صغيرة، مع الاحتفاظ بالمسارات النسبية والتحقق من الحجم قبل إضافة الملفات للمستودع.
2. بعد كل مستوى: فحص الصور والصوتيات، فتح صفحات الدروس داخل الموقع نفسه، ثم إضافة مسارات محلية لا روابط Drive للطلاب.
3. مطابقة كل درس ونشاط وقاعدة مع ملفات الكتاب/المدرس، وتوسيع بنوك الأسئلة والقصص بعد التحقق من المصدر.
4. اختبار فعلي للهاتف واللابتوب والميكروفون، ومعالجة نتائج المتصفحات غير الداعمة برسالة واضحة.
5. إنشاء تقرير تحقق منفصل لكل حزمة أصلية بعد اكتمال استيرادها؛ لا تخلط بيانات الأمثلة الحالية بأرشيف التسجيلات التاريخي.
