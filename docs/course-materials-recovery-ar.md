## الاستيراد والفحوص

بعد تنزيل ZIPs المطلوبة إلى `google_drive/` يمكن تحديث A1 أو A2.2/A2.3 حسب الحاجة، دون استبدال إدخالات القارئات الأخرى:

```bash
python3 scripts/import-book-readers.py --only A1.1 A1.2 A1.3
python3 scripts/import-book-readers.py --only A2.2 A2.3
```

استيراد صفحات A2 يتطلب ImageMagick (`magick` أو `convert`) مع دعم WebP. ولإعادة بناء بيانات الأنشطة المحلية المستقلة عن التفريغات، استخدم `npm run extract:course-assets`.

- `npm run materials:check`: يفحص ملفات الصور والصوت، ومسارات كل درس، وصفحات الصوت المرتبطة.
- `npm run quality:check`: يفحص القارئات الست، JavaScript المضمّن، وإخفاء أدوات المعلم والروابط الخارجية، إضافة إلى مواد الدروس.
- `npm run build`: يبني تطبيق Vite.

هذه الفحوص بنيوية؛ لم يُجر اختبار بصري/تفاعلي في متصفح حقيقي في هذه الجولة. أُجري اختبار HTTP محلي لـ599 مسارًا لصور الصفحات والصوتيات والقارئات. دمج القارئ لا يحوّل كل نشاط صفحة إلى تمرين React مستقل، ولا يعني أن كل صفحات الكتاب أو حلول المعلم استُعيدت.
