# Hola — الإسباني بالمصري

تطبيق ويب تعليمي mobile-first لتعلّم الإسباني بشرح عربي مصري. النسخة الحالية نموذج تفاعلي أولي، ومنهجها سيتنظم على خريطة مستويات كتب Difusión: Aula internacional Plus 1–5 ثم Aula C1 للمستوى C1.

## تشغيل المشروع

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

لإعادة توليد بيانات الأمثلة المحلية وتشغيل فحص الجودة:

```bash
npm run extract:course-assets
npm run quality:check
```

## الموجود حاليًا

- واجهة عربية RTL متجاوبة للموبايل والتابلت واللابتوب: شريط تنقل سفلي على الشاشات الأصغر، قائمة جانبية على الشاشات الأوسع، وشبكات مرنة للمحتوى والدرس المنبثق.
- خريطة المستويات A1، A2، B1، B2.1، B2.2، وC1 مع ربط بالمجلدات المناسبة من Aula internacional Plus وAula C1.
- مسار A1 داخل التطبيق: الوحدات 0–9، ولكل وحدة درس تفاعلي أصلي. فيه مود كورس بالترتيب العادي مع التالي/السابق، يبدأ من الوحدة 0 ويمشي لحد 9، أو يبدأ من أول وحدة في A1.1 أو A1.2 أو A1.3. تقسيم Drive هو A1.1 للوحدات 0–3، وA1.2 للوحدات 4–6، وA1.3 للوحدات 7–9؛ بطاقة A1 فيها روابط HTML v53 وحزمة ZIP الكاملة v53 لـA1.1، وروابط مواد A1.2. رابط HTML على Drive معاينة للمصدر وليس استضافة للموارد النسبية؛ لم تُنسخ الحزمة كاملة إلى ملفات التطبيق بعد. مجلد A1.3 موجود لكن مفيهوش ملفات حاليًا، ودروسه متاحة داخل مود الكورس.
- مرجع الكتاب وبرنامج الوحدات ومواد إعداد المدرّس التفصيلية المتاحة للوحدات U0–U5 موجودة في مجلد A1 الأول؛ برنامج الناشر المنشور مرجع تحقق إضافي، مش بديل عن مواد Drive.
- مسار A2 مبني على طبعة الكتاب ذات 10 وحدات وملفات التخطيط والتدقيق في مجلد Drive الثاني، ولكل وحدة درس تفاعلي أصلي. بطاقة A2 تشير إلى أحدث حزمة A2.1 كاملة وجدناها (v190، عُدّلت 13 نوفمبر 2026). ملف `index.html` منفصل في Drive عُدّل 3 نوفمبر 2026، أقدم من الحزمة، لذلك لا نعرضه كأحدث نسخة. رابط ZIP يفتح المصدر في Drive فقط؛ تشغيل HTML بموارده النسبية يتطلب فك الحزمة ووضع `index.html` بجوار مجلدات `pages` و`audio` و`fonts` و`docs`، ولم تُنسخ الحزمة محليًا بعد. دليل التدقيق المرفق تقرير داخلي للمجلد، مش اعتمادًا من الناشر.
- الخطة التدريسية الأصلية لـA2 مقسّمة إلى A2.1 للوحدات 1–4، وA2.2 للوحدات 5–8، وA2.3 للوحدات 9–10 والمراجعة الشاملة: 12 لقاء × 3 ساعات (36 ساعة). ملف الخطة يحدد كذلك 72 مهمة قصيرة و72 رسالة مساندة؛ الأعداد دي مخرجات مخططة، مش ادعاء إن كل الرسائل والمهام اتبنت بالفعل.
- فصل واضح بين **مصادر الكتاب** (الفهرس، القواعد، المفردات والمواد التي يتيحها المجلدان) و**خطة التدريس الأصلية** (تقسيم A2، الشرح بالمصري، أنشطة التطبيق والاختبارات). محتوى الدروس الرقمية صياغة أصلية ولا يعيد نشر صفحات الكتاب.
- لوحة رئيسية، قاموس كلمات، صفحة إنجازات وألعاب مطابقة.
- الدروس فيها مفردات ونطق وأمثلة وقاعدة قصيرة واختبار تفاعلي، ومحتواها العربي بالمصري.
- صفحة **استمعي وترجمي** تعرض أمثلة الجمل الإسبانية وترجماتها العربية الكاملة من محتوى الدروس المحلي، مع تبويبين منفصلين للنص الإسباني والترجمة العربية. نص الترجمة لا يضيف إليه اسم وحدة أو نشاط، والبحث والتصفية يعملان على الأمثلة المحلية.
- بيانات الاستماع الحالية 20 مثالًا مأخوذًا من `src/data/lessons.js`، وليست نسخة مستعادة من أرشيف التسجيلات التاريخي. لا تُستخدم ملفات التفريغ الإسبانية في Drive مصدرًا للترجمة. زر الاستماع يستخدم Speech Synthesis في المتصفح، وليس تسجيلًا صوتيًا من الكتاب.
- سكربت الاستخراج يولّد ملفات `activity-data.json` لأربع مراحل من خريطة الدروس المحلية: A1.1 وA1.2 وA1.3 وA2.1، إضافة إلى `scripts/listening-translations.json`.
- فحص الجودة يتحقق من مطابقة الترجمات المحلية، وفصل التبويبات، وغياب علامات النشاط/الوحدة من نص الترجمة، واتساق ملفات المواد الأربعة.
- حفظ تقدّم تجريبي محليًا في المتصفح ورسومات SVG أصلية.

## الخطة التعليمية

البرنامج هيعلّم الإسباني **باللغة العربية المصرية**، ويستهدف محتوى شامل ودقيق ومتدرّج، وطموحنا نحسّن التجربة باستمرار بقياس الوضوح والتفاعل والتقدّم — من غير ادّعاء تفوّق على البرامج الكبيرة من غير مقارنة موثّقة. كل وحدة تربط أهداف التواصل بالمفردات والقواعد ومهارات القراءة والاستماع والنطق والمحادثة والكتابة، مع مراجعة واختبار مناسبين للمستوى. خريطة A2 هنا لطبعة الكتاب ذات 10 وحدات في مجلد Drive وخطة التدريس الأصلية المرفقة بها؛ مانخلطهاش ببرنامج Plus 2 مختلف في عدد الوحدات أو الساعات.

- **صور تعليمية:** هنتوسع في رسومات وصور أصلية للمفردات والمواقف (زي الفصل والبيت والحي والأكل والصحة). الموجود حاليًا رسمة SVG أصلية؛ الصور الخاصة بكل وحدة هتتضاف على مراحل، ومن غير إعادة استخدام صفحات الكتاب.
- **ألعاب:** فيه لعبة مطابقة مفردات، وخطة ألعاب تانية مرتبطة بأهداف الوحدات، زي اسمع واختار وبطاقات المراجعة.
- **شرح القواعد:** شرح بالمصري، مثال واضح، تدريب متدرّج، وتطبيق تواصلي؛ زي نماذج القواعد الموجودة في دروس A1 وA2.
- **الصوت:** نطق إسباني مولّد من المتصفح، مش تسجيلات الكتاب؛ جودته وتوفره بيعتمدوا على الجهاز.

## إزاي المساعد يقدر يساعد في إنشاء البرنامج؟

يقدر المساعد ينظّم مسار A1 وA2 حسب المصدر والطبعة، ويكتب شروحًا وتمارين أصلية بالمصري، ويقترح صورًا وأنشطة وألعابًا، ويجهّز أمثلة وصوتًا إسبانيًا مولّدًا، ويراجع دقة القواعد وتدرّج المحتوى واتساقه ويصلّح الملاحظات مع المستخدم خطوة بخطوة. المحتوى المحمي للكتاب مش بيتنسخ أو يعاد نشره.

الوحدات العشر في A2 وعلاقتها بصفحات الكتاب راجعناها على ملف التدقيق الموجود في مجلد Drive نفسه؛ التقرير داخلي وليس اعتمادًا من الناشر. برنامج الناشر المتاح لـPlus 2 ذي 80 ساعة يعرض تنظيمًا مختلفًا من 8 وحدات، لذلك لا نستخدمه لتحديد محتوى أو زمن خطة Drive ذات 10 وحدات و36 ساعة. المستويات الأعلى لسه خريطة مبدئية.
