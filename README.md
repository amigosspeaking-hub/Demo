# Hola — الإسباني بالمصري

تطبيق ويب عربي متجاوب لتعلّم الإسبانية. المحتوى والأنشطة الحالية محلية، والواجهات لا تفتح ملفات Google Drive للطالب.

## التشغيل والتحقق

```bash
npm install
npm run dev
npm run build
npm run extract:course-assets
npm run quality:check
npm run materials:check
```

## ما تم تنفيذه في النسخة الحالية

- صفحات مستقلة داخل التطبيق للمحاضرات، والجرامر، والاستماع، والتحدث، وصالة الألعاب، وQuiz، وFlashcards، والامتحانات، والكلمات، والإنجازات، والملف الشخصي. التنقل لا يفتح نوافذ خارجية.
- اختيار المستوى النشط من الملف الشخصي: A1.1 وA1.2 وA1.3 وA2.1 وA2.2 وA2.3. الاختيار والتقدم والكلمات المحفوظة تحفظ محليًا في المتصفح، وتفلتر الصفحات.
- 20 نموذج محاضرة أصليًا داخل `src/data/lessons.js` (10 وحدات A1 و10 وحدات A2)، مع أمثلة ومفردات واختبار قصير. تقسيم المراحل A1/A2 مبني على خريطة المشروع المحلية.
- 20 دليل قواعد بالمصري في `src/data/grammar.js`، و20 قصة ثنائية اللغة في `src/data/stories.js`، وبنوك جمل متعددة في `src/data/sentences.js`.
- أربع آليات ألعاب منفصلة: المطابقة، والاختيار، والاستماع والاختيار، وترتيب الجملة. كل لعبة تبدأ في شاشة لعب خاصة بمحاضرة ومستوى محددين، مع وقت وقلوب ونقاط وتغذية راجعة داخل الصفحة.
- صفحة استماع ثنائية اللغة: الإسبانية يسارًا باتجاه LTR والعربية يمينًا، وزر إظهار/إخفاء الترجمة، وسرعات نطق 0.5 و0.75 و1 و1.25. وأضيفت تسجيلات الكتاب الأصلية المتاحة كمشغل مستقل مرتبط بمحاضرة المستوى الحالي.
- استيراد 362 صفحة كتاب مميزة بصيغة WebP و120 ملف MP3 أصليًا (تشمل النسخ البديلة) لخريطة مواد المحاضرات في A1.1–A1.3 وA2.1–A2.3. قارئات A1 الأصلية تشمل صفحات الدعم المفهرسة: A1.1 (121/121)، A1.2 (81/81)، A1.3 (79/86)؛ سبع صور تفريغ مفهرسة لـA1.3 (1025–1031) لم توجد في أرشيفات الصور التي فُحصت، وتُستبعد من القارئ بدل عرض روابط مكسورة. تفتح المواد من محاضرتها داخل التطبيق، لا عبر روابط خارجية.
- صفحة تحدث تستخدم واجهة التعرف الصوتي المتاحة في المتصفح، وتقارن النص المسموع بالنموذج كلمة بكلمة. لا يوجد بديل كتابة للجملة.
- Flashcards تقلب بألوان متباينة وتتصل ببنك الكلمات المحفوظة، والامتحان وQuiz يعملان كصفحتين منفصلتين.
- الواجهة RTL للعربية وLTR لمحتوى الإسبانية، مع ألوان مستلهمة من الأحمر والأصفر والأخضر الإسباني، وتصميم متجاوب.
- اختبارات الجودة تفحص اتساق أمثلة الدروس وترجماتها، ووجود شرح وقصة وبنك جمل لكل درس، ومواد المراحل؛ كما تتحقق من ملفات القارئات الست و362 صورة WebP و120 ملف MP3.

## حدود يجب عدم إخفائها

هذه النسخة **ليست المحتوى الكامل للكتاب أو استعادة كاملة للأرشيف التاريخي**. الدروس التفاعلية ما تزال 20 نموذجًا، لكن قارئات الكتاب الأصلية ومواد الوحدات موصولة الآن لكل محاضرات A1 وA2.2–A2.3، إضافة إلى A2.1. الحزمتان المفحوصتان لـA2.2/A2.3 تحتويان 58 ملف MP3 (منها بدائل)، ولا تساويان أرشيف 56 تسجيلًا بالضبط. لم نعثر بعد على مصدر موثوق يطابق أرشيف 861 صف ترجمة: ملف `transcripts_v17.json` المستعاد يغطي 24 مسارًا و401 سطر/مداخلة تقريبًا، و`transcripts_raw.txt` نص إسباني مطبوع من 20 صفحة A1، وليس قاعدة ترجمة منظمة من 861 صفًا. تظهر صفحات تفريغ الكتاب داخل القارئ، لكن لا توجد ترجمة عربية سطرية موثقة لكل التسجيلات؛ أمثلة الاستماع الثنائية المحلية منفصلة عن صوت الكتاب. نطق Speech Synthesis من الجهاز منفصل عن MP3 الكتاب. B1 إلى C1 خريطة مستقبلية وليست وحدات منفذة.

تقارير وتفاصيل الاستعادة: `docs/course-materials-recovery-ar.md` و`docs/course-materials-import-manifest.json`. لا تظهر روابط Drive في واجهة الطالب.

- `public/materials/A2.2/activity-data.json`
- `public/materials/A2.3/activity-data.json`

هذه بيانات تدريب مشتقة من الدروس النموذجية المحلية، وليست تفريغ التسجيلات التاريخي. قارئات HTML وصفحات WebP وصوتيات الكتب موجودة منفصلة تحت `public/materials/readers/` و`public/materials/books/`. `npm run quality:check` يتحقق من 20 مثالًا وستة ملفات مواد ومواد الكتب المحلية، لكنه لا يدّعي اكتمال أرشيف 56/861.
